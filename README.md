# ARC Daily — Privacy Policy & Support

Public, static GitHub Pages website for ARC Daily.

## Website pages
- `index.html` — landing page
- `privacy-ko.html` — Korean privacy policy
- `privacy-en.html` — English privacy policy
- `support-ko.html` — Korean support
- `support-en.html` — English support
- `styles.css` — styling

## How to publish
1. Unzip the downloaded archive.
2. In the `arc-daily-legal` GitHub repository open **Add file → Upload files**.
3. Upload all six listed files directly to the repository's root (not the ZIP itself and not a nested folder).
4. Click **Commit changes** on the `main` branch.
5. Ensure Settings → Pages uses `Deploy from a branch` / `main` / `/(root)`.
6. Open `https://baekseung0831-star.github.io/arc-daily-legal/`.

## Before publication / App Store submission
- Confirm final IPA data processing and all bundled SDKs.
- Verify legal operator disclosures, applicable Korean privacy-law obligations and any EU privacy-law obligations before relying on this draft as a legally complete policy.
- Add a policy link to the ARC Daily app settings screen.
- Update the policy if advertising, analytics, sign-in, subscriptions or network transmission is added.
- Never upload secrets or identification documents to this public repository.
